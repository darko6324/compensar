Lógica de ANS

Respuesta Inicial

Tiempo máximo de 1 día hábil para dar respuesta a una no conformidad registrada.

Plan de Acción

Tiempo máximo de 3 días hábiles para presentar un plan de acción correctivo.

Cumplimiento

El sistema evalúa automáticamente la columna CUMPLIMIENTO ANS para calcular el % de éxito.

Sobre este Dashboard

Este BI se conecta directamente a Google Sheets vía PapaParse y procesa 5 hojas de trabajo en tiempo real. Los datos se agrupan automáticamente por mes para facilitar el análisis de tendencias.
